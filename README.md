## 📖 Project Overview

DocAppoint is a full-stack Doctor Appointment Management System that allows users to browse doctors, book appointments, and manage their bookings through a secure and user-friendly interface.

---

## ✨ Features

- 🔐 Secure JWT Authentication using HttpOnly Cookies.
- 👨‍⚕️ Browse all available doctors with detailed profiles.
- 📅 Book appointments by selecting available time slots.
- 📋 View, update, and delete booked appointments.
- 🔒 Protected routes ensure only authenticated users can access appointment features.
- 📱 Fully responsive design for desktop, tablet, and mobile devices.
- ⚡ Fast and modern user interface built with Next.js and Tailwind CSS.
